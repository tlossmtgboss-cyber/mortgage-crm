## Workflow Categories

### Sales Team (2 members)
- **Focus:** Lead generation, client acquisition, loan origination
- **Key Metrics:** Number of applications, conversion rates, pipeline value
- **Primary Tools:** CRM, rate sheets, pre-qual calculators

### Production Assistants (2 members)
- **Focus:** File coordination, processing support, closing preparation
- **Key Metrics:** Files to close, condition clearance time, closing success rate
- **Primary Tools:** LOS, document management, communication tools

### Concierge (1 member)
- **Focus:** Client experience, communication, satisfaction
- **Key Metrics:** Client satisfaction scores, response time, review collection rate
- **Primary Tools:** Communication platforms, survey tools, CRM

### Processors (2 members)
- **Focus:** File review, underwriting prep, condition management
- **Key Metrics:** Files submitted, turnaround time, approval rate
- **Primary Tools:** LOS, AUS systems, document review platforms

### Processor Assistants (2 members)
- **Focus:** Document management, data entry, administrative support
- **Key Metrics:** Documents processed, data accuracy, turnaround time
- **Primary Tools:** Scanner, LOS, filing systems

### Executive Support (1 member)
- **Focus:** Leadership support, team coordination, reporting
- **Key Metrics:** Meeting efficiency, report accuracy, event success
- **Primary Tools:** Calendar, presentation software, analytics tools

## Using This Team for Testing

### Impersonation
To view each team member's workflow:
1. Navigate to the Team page in the CRM
2. Click on a team member
3. Use the "Impersonate" feature (if available) or view their assigned tasks

### Adding Responsibilities
Team responsibilities can be added by users with Manager role through:
- User Profile → Responsibilities Tab
- Direct API calls with proper authentication

### Viewing Workflows
Each team member's workflow can be viewed in:
- Individual user profiles
- Team dashboard
- Workflow/process management pages
