# Borrower Portal Consolidation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Read "Verified Facts" at the bottom before starting — your instinct about which portal is canonical is almost certainly wrong.**

**Goal:** Collapse 7 overlapping borrower-portal components (~4,680 lines) into one canonical stack with no feature regression, then delete the dead implementations and consolidate the duplicate API clients.

**Architecture:** The canonical live portal is `PortalContainer` (`/portal/:slug`), a stage router that detects workspace lifecycle stage and lazy-loads one of three stage portals: `LeadPortal`, `ActiveLoanPortal`, `MUMPortal`. Every borrower link generated by the backend points here (`purl_routes.py:1636,1714,2153,2403,2526`; `borrower_auth_routes.py:2858`). Two large components — `PerenniaClientPortalUltimate` (1,537 lines) and `ActiveLoanPortalComplete` (531 lines) — are **abandoned rewrites with zero inbound links** but contain valuable features missing from the live portals. We harvest those features into the live stage portals **first**, then delete the dead files. `BorrowerPortal` (`/borrower-portal/:token`, a live auth-redirect fallback) folds into the canonical stack via redirect. Finally we standardize the three competing API clients onto the dominant one.

**Decisions locked (do not relitigate):**
- Harvest valuable features **before** deleting dead code (no regression).
- `/borrower-portal/:token` becomes a redirect into `/portal/:slug`; the component is retired.

**Tech Stack:** React (JSX/TSX), React Router, WebSocket + polling, FastAPI/SQLAlchemy backend (link generation only), Vitest/Jest for frontend tests.

**Ordering rule:** Nothing irreversible happens before its safety net exists. Redirects (Task 1) precede deletion (Task 3). Harvest (Task 2) precedes deletion (Task 3). API cleanup (Task 5) is last — independent and lowest risk.
