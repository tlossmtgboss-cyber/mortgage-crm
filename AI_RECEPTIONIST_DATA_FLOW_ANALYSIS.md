## Problem Statement

From user screenshots:
- **AI Receptionist Dashboard** shows: 8 conversations, 0 appointments, 100% AI coverage, 0 errors
- **Settings Page KPIs** show: 0 Total Calls, 0 Inbound, 0 Outbound, 0 Leads Generated

**Issue:** Data is being logged but NOT fully flowing to all dashboard metrics.

---

## Data Flow Analysis

### ✅ What's Working

1. **Vapi Webhook Integration** (`vapi_routes.py:70-99`)
   - Endpoint: `/api/vapi/webhook`
   - Receives call data from Vapi
   - Calls `VapiCRMIntegration.process_call_webhook()`

2. **Call Logging to Database** (`vapi_service.py:159-227`)
   - Saves calls to `vapi_calls` table
   - Extracts transcript, sentiment, summary
   - Links to leads in CRM

3. **Dashboard Logging Exists** (`vapi_service.py:305-357`)
   - Method: `_log_to_dashboard()`
   - Creates `AIReceptionistConversation` record
   - Creates `AIReceptionistActivity` record
   - Links to original Vapi call via `extra_data->>'vapi_call_id'`

### ❌ What's Missing/Broken

1. **Daily Metrics Aggregation**
   - Table `ai_receptionist_metrics_daily` is likely EMPTY
   - No cron job or background task to aggregate daily stats
   - Settings page KPIs read from this table → Shows 0 for everything

2. **Appointment Tracking Gap**
   - When `schedule-appointment` function is called (`vapi_routes.py:427-531`):
     - ✅ Creates `Activity` record (for calendar)
     - ✅ Creates `Task` record (for follow-up)
     - ❌ Does NOT create `AIReceptionistActivity` with `action_type='appointment_booked'`
   - Result: Appointments aren't counted in dashboard

3. **Lead Generation Tracking**
   - Vapi creates leads with `source='vapi_call'` or `'AI Phone Call'`
   - ❌ No corresponding `AIReceptionistActivity` created for new lead capture
   - Settings KPIs can't count leads generated by AI

4. **Outbound Call Tracking**
   - Outbound calls exist in `vapi_calls` with `direction='outbound'`
   - ❌ Not separately counted in dashboard metrics

## Solutions Required

### 1. ✅ CRITICAL: Create Daily Metrics Aggregation Job

**What:** Background job that runs daily (or hourly) to aggregate activity data

**Implementation:**
```python
# backend/jobs/aggregate_dashboard_metrics.py

from sqlalchemy import func, and_
from datetime import date, datetime, timezone, timedelta
from ai_receptionist_dashboard_models import (
    AIReceptionistActivity,
    AIReceptionistMetricsDaily
)

def aggregate_daily_metrics(db, target_date=None):
    """Aggregate activity data into daily metrics"""
    if not target_date:
        target_date = date.today()

    day_start = datetime.combine(target_date, datetime.min.time()).replace(tzinfo=timezone.utc)
    day_end = datetime.combine(target_date, datetime.max.time()).replace(tzinfo=timezone.utc)

    # Count activities by type
    activities = db.query(AIReceptionistActivity).filter(
        and_(
            AIReceptionistActivity.timestamp >= day_start,
            AIReceptionistActivity.timestamp <= day_end
        )
    )

    total_conversations = activities.filter(
        AIReceptionistActivity.action_type.in_(['incoming_call', 'incoming_text'])
    ).count()

    inbound_calls = activities.filter(
        AIReceptionistActivity.action_type == 'incoming_call'
    ).count()

    inbound_texts = activities.filter(
        AIReceptionistActivity.action_type == 'incoming_text'
    ).count()

    appointments = activities.filter(
        AIReceptionistActivity.action_type == 'appointment_booked'
    ).count()

    escalations = activities.filter(
        AIReceptionistActivity.action_type == 'escalated'
    ).count()

    # Calculate AI coverage
    ai_coverage = (1 - (escalations / max(total_conversations, 1))) * 100 if total_conversations > 0 else 0

    # Check if record exists for this date
    existing = db.query(AIReceptionistMetricsDaily).filter(
        AIReceptionistMetricsDaily.date == target_date
    ).first()

    if existing:
        # Update existing
        existing.total_conversations = total_conversations
        existing.inbound_calls = inbound_calls
        existing.inbound_texts = inbound_texts
        existing.appointments_scheduled = appointments
        existing.escalations = escalations
        existing.ai_coverage_percentage = ai_coverage
    else:
        # Create new
        metric = AIReceptionistMetricsDaily(
            date=target_date,
            total_conversations=total_conversations,
            inbound_calls=inbound_calls,
            inbound_texts=inbound_texts,
            appointments_scheduled=appointments,
            escalations=escalations,
            ai_coverage_percentage=ai_coverage
        )
        db.add(metric)

    db.commit()
    return total_conversations
```

```python
@router.post("/admin/aggregate-metrics")
async def trigger_metrics_aggregation(
    days: int = Query(7, description="Number of days to aggregate"),
    db: Session = Depends(get_db)
):
    """
    Manually trigger metrics aggregation
    Useful for backfilling or testing
    """
    try:
        from datetime import date, timedelta
        from jobs.aggregate_dashboard_metrics import aggregate_daily_metrics

        results = []
        for day_offset in range(days):
            target_date = date.today() - timedelta(days=day_offset)
            count = aggregate_daily_metrics(db, target_date)
            results.append({
                "date": str(target_date),
                "conversations_aggregated": count
            })

        return {
            "success": True,
            "message": f"Aggregated metrics for {days} days",
            "results": results
        }
    except Exception as e:
        logger.error(f"Error aggregating metrics: {e}")
        raise HTTPException(status_code=500, detail=str(e))
```
