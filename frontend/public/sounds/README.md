# Sound Files

This folder contains sound files for the portal notifications.

## Required Files

- `youve-got-mail-sound.mp3` - Played when the user first visits the portal and has new tasks to complete

## Adding the Sound File

Place your "You've Got Mail" sound file in this folder and name it `youve-got-mail-sound.mp3`.

The sound should be:
- Short (1-3 seconds)
- A pleasant notification tone
- Not too loud

## Usage

The sound plays automatically when:
1. A user first visits the portal
2. There are new/incomplete tasks to complete

The sound will only play once per session to avoid being annoying.
