Remaining Findings (Non-Blocking)

HIGH  R1: NMLS Error Handling

Public booking raises NMLSBlockingError but doesn't catch it — returns 500 instead of 403. Booking IS blocked, but with wrong HTTP status.

HIGH  R2: SendGrid Webhook Signature

SENDGRID_WEBHOOK_VERIFICATION_KEY read but never used to validate inbound webhook signatures. Rate limiting mitigates but doesn't eliminate risk.

HIGH  R3: Outbound Webhook HMAC

Webhook secrets stored encrypted but not used to sign outbound payloads. Consumers can't verify event authenticity.

HIGH  R4: Persist Suppression List

Email suppression list is in-memory — lost on restart. Should migrate to database table for durability.

MED  R5: Per-Org Sitemaps

sitemap.xml queries across all orgs. Should filter by organization_id for multi-tenant SEO.

MED  R6: Email Template Branding

Email templates hardcode "Perennia AI" footer. Should support org-level customization.

MED  R7: CSV Import/Export

Bulk operations accept JSON only. CSV import/export for enterprise data migration.

MED  R8: Bulk Dry-Run Mode

All bulk endpoints commit immediately. Dry-run/preview mode for safe migration.

Architecture Highlights

Rate Limiting

Redis-backed with async in-memory fallback. Bounded capacity — refuses new keys when full instead of evicting (prevents IP rotation attacks). Per-IP extraction from X-Forwarded-For with trusted proxy validation.

Circuit Breaker

Three-state pattern (CLOSED/OPEN/HALF_OPEN) for SendGrid. Configurable failure threshold and recovery timeout via environment variables. Thread-safe with Lock.

Webhook Delivery

3-attempt retry with exponential backoff (2s, 4s, 8s). Dead-letter queue with admin notifications. Manual retry API. Health monitoring with success rate tracking.

Background Jobs

15 scheduled jobs staggered across different minute offsets. Per-record try/except isolation. Session cleanup in finally blocks. Per-org batching for cache efficiency.
